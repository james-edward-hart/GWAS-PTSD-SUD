FIX THE GRCh38 ADMIXTURE REFERENCE PACKAGE
===========================================

Problem
-------

The GRCh38 ADMIXTURE BED/FAM contains 3,202 samples, while metadata.tsv
contains 2,573. The 629 genotype-only samples are the official PLINK2
first/second-degree related-sample exclusions.

The builder downloaded a one-column removal file with this shape:

#IID
HG00405
...

It then added FID to the source PSAM, producing two-part FID/IID sample IDs,
but passed the original one-column file to PLINK2 --remove. The genotype
filter therefore matched no samples. The metadata writer independently read
the first column and did remove all 629 samples.

Do not add labels for the 629 samples, mark them as study samples, or remove
only HG00405. Rebuild the affected panel with a two-column FID/IID removal
file. This is required for scientific integrity and for supervised ADMIXTURE.


Expected final state
--------------------

The repair is complete only when all of these are true:

* The official removal file has SHA-256
  22094d03c593276ba88ea5c564e106bab2a755f0d2a3e6c77aaff2f8bcd83b66.
* The repaired GRCh38 FAM has 2,573 samples.
* Its FID/IID set exactly equals the GRCh38 metadata FID/sample_id set.
* The original 3,202-sample set minus the repaired set exactly equals the
  official 629-sample removal set.
* Metadata contains 2,573 unique, completely labeled samples:
  AFR=680, AMR=351, EAS=506, EUR=525, SAS=511.
* The repaired BIM has unique IDs and unique chromosome/position coordinates.
* Package validation, fingerprint validation, and archive checksum validation
  all pass.
* A rerun reports 2,573, not 3,202, reference samples.

3. Build matching two-part sample IDs
-------------------------------------

Create the same FID=IID convention used by the package, and translate the
official one-column removal file to headerless FID/IID pairs for PLINK2.

python3 - "$CACHE/hg38_corrected.psam" "$WORK/input/all_hg38.psam" <<'PY'
import sys

source, target = sys.argv[1:3]
with open(source) as inp, open(target, "w") as out:
    header = inp.readline().rstrip("\n").split("\t")
    if not header or header[0] != "#IID":
        raise SystemExit("expected hg38_corrected.psam to begin with #IID")
    out.write("#FID\tIID\t" + "\t".join(header[1:]) + "\n")
    for line in inp:
        fields = line.rstrip("\n").split("\t")
        if not fields or not fields[0]:
            raise SystemExit("empty IID in corrected PSAM")
        out.write(fields[0] + "\t" + "\t".join(fields) + "\n")
PY

4. Rebuild only the GRCh38 ADMIXTURE panel
-----------------------------------------

This repeats the original builder filters, but --remove now receives matching
FID/IID pairs. MAF is intentionally recalculated after removal; filtering the
existing BED alone would not faithfully reproduce the intended build.

"$PLINK2" \
  --pfile "$WORK/input/all_hg38" vzs \
  --chr 1-22 \
  --snps-only just-acgt \
  --max-alleles 2 \
  --maf 0.01 \
  --remove "$WORK/input/deg2_hg38.remove.tsv" \
  --rm-dup exclude-all \
  --make-pgen \

builder contract:

5. Regenerate metadata from the same source and exclusion list
--------------------------------------------------------------

python3 - \
  "$WORK/input/all_hg38.psam" \
  "$CACHE/deg2_hg38.king.cutoff.out.id" \
  "$WORK/output/metadata.tsv" <<'PY'
import csv
import sys

psam_path, remove_path, output_path = sys.argv[1:4]

with open(remove_path) as handle:
    if handle.readline().strip() != "#IID":
        raise SystemExit("expected removal file header #IID")
    remove = {line.strip() for line in handle if line.strip()}

if len(remove) != 629:
    raise SystemExit(f"expected 629 removal IDs, observed {len(remove)}")

with open(psam_path, newline="") as inp, open(
    output_path, "w", newline=""
) as out:
    reader = csv.DictReader(inp, delimiter="\t")
    required = {"#FID", "IID", "Population", "SuperPop", "SEX"}
    missing = required.difference(reader.fieldnames or [])
    if missing:
        raise SystemExit(f"corrected PSAM missing columns: {sorted(missing)}")

    fields = [
        "sample_id", "FID", "population", "super_population", "sex"
    ]
    writer = csv.DictWriter(out, delimiter="\t", fieldnames=fields)
    writer.writeheader()
    for row in reader:
        if row["IID"] in remove:
            continue
        writer.writerow({
            "sample_id": row["IID"],
            "FID": row["#FID"],
            "population": row["Population"],
            "super_population": row["SuperPop"],
            "sex": row["SEX"],
        })
PY

Scientific-integrity note
-------------------------

The 629-sample exclusion is not an optimization. It is part of the declared
GRCh38 reference-panel sample definition and prevents close relatives from
being treated as independent supervised reference observations. The repair
must retain the official checksum, exact set comparisons, rebuilt MAF filter,
and new package fingerprint. Never reuse the old fingerprint or archive
checksum after changing the panel.
